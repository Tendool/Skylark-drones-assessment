# Skylark Drones BI Agent — frontend

React + Vite chat UI for the backend in `../backend`. See the root
[`README.md`](../README.md) for the full setup, run, and deploy instructions.

```bash
npm install
npm run dev      # dev server on :5173, calls the backend at VITE_API_BASE (see .env.development)
npm run build    # outputs dist/, which backend/main.py serves directly when present
```
